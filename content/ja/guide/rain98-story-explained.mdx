## Rain98 とは何か、わかりやすく言うと

Rain98 は物語重視のビジュアルノベルで、非常に独特な雰囲気を持っている。冷たい青い光、CRT時代の不安、そして1998年に撮影されて引き出しにしまわれたままの夜の街。その前提は意図的に挑発的だ――過去へ戻り、世界を終わらせることを目標として掲げるタイムトラベルの物語なのだ。

それがこの作品のフックであり、同時にこのゲームをめぐる議論の多くが、実のところ「トーン」についての議論になる理由でもある。Rain98 は歴史を修正するというパワーファンタジーを売っているのではない。売っているのは「ムード」だ。現在は疲れ果てており、過去もまたそうだった、という感覚。物語のそれ以外のすべて――技術、タイムライン、人間関係――は、この考えにぶら下がっている。

## すべてを形づくる平成の背景

日本の平成時代はバブル経済の崩壊の後に始まり、やがて「失われた数十年」と呼ばれる時代へと滑り込んでいった――長く続く停滞、不安定な雇用、そして広く行き渡った制度への失望。その歴史は Rain98 において単なる飾りではない。それがエンジンなのだ。

1990年代後半から2000年代初頭にかけて、日本のメディアはその不安を、奇妙で不穏な芸術へと代謝する波を生み出した。*Serial Experiments Lain*、*新世紀エヴァンゲリオン*、*リリイ・シュシュのすべて* は Rain98 と並べて語られることの多い参照点であり、その親近性は微妙なものではない。内省的な主人公、敵意あるいは無関心なシステム、そしてきれいに決着することを拒む結末。

その系譜を理解することが、このゲームが何をしているのかを理解する最短の道だ。Rain98 は平成時代を可愛らしいレトロフィルター的な方法で懐かしんでいるのではない。もっと居心地の悪い意味で懐かしんでいるのだ――当時の人々が感じていた不安は実際には決して消え去ったのではなく、ただ服を着替えただけだと認識しながら。

| 影響元 | 時代 | Rain98 に与えているもの |
| --- | --- | --- |
| *Serial Experiments Lain* | 1990年代後半 | ネットワーク的な疎外感、溶けていくアイデンティティ、冷たい青のパレット |
| *新世紀エヴァンゲリオン* | 1990年代半ば | 鎧としての無気力、終末的な緊張感、心理的な内面性 |
| *リリイ・シュシュのすべて* | 2000年代初頭 | 思春期の不満、静かな不安、デジタルへの逃避 |

## ひねりのあるタイムトラベル：二つの時代、一つの共有された frustration

ほとんどのタイムトラベル物語は対比で動く。壊れた現在から来た誰かが黄金の過去へ旅する、あるいは快適な現在から厳しい未来を訪れる。Rain98 はその対比を平坦化することで逆転させる。世界は今も悪く、そして当時も悪かったのだ。

これがこのゲームの最も賢い構造的アイデアであり、Rain98 のストーリー解説を自分なりのやり方で追いたいなら注目すべき点だ。歴史の異なる時点から来た二人のキャラクターが出会い、どちらも自分の物質的な状況を受け入れられない。どちらも「昔はもっと良かった」と信じる贅沢を持っていない。ドラマは、同じ失望の二つのバージョンについて二人が情報交換するのを見守ることから生まれる。

| 次元 | 過去（平成時代） | 現代 |
| --- | --- | --- |
| 経済的な空気 | バブル後の停滞、失われた数十年 | 不安定な雇用、生活費への不安 |
| 文化的な産物 | 不穏で、内省的で、実験的 | 同じ空気のノスタルジックな復活 |
| キャラクターの反応 | 引きこもりと運命論 | 皮肉と疲労 |
| 共有された問い | なぜ何も変わらないのか？ | なぜ何も変わらなかったのか？ |

この構造が「世界を終わらせる」という前提に何をもたらすかに注目してほしい。もし両方の時代がすでに腐食しているなら、世界を破壊することは実際には破壊行為ではない――拒絶の行為なのだ。それは、これほど多くの静かな惨めさを生み出すシステムは存続するに値しない、とあるキャラクターが言うための方法だ。ゲームがそれを肯定するのか、それとも問い質すのかは、完全版が答えるべき中心的な問いである。

## Serial Experiments Lain のDNAを解説する

誰かがその名前を口にする前に、*Lain* の影響は感じ取れる。プロモーションアートだけでも物語を語っている。明らかに疲れ果てた女性がタバコを手に、輝く夜の街を見下ろすバルコニーに立ち、頭の上には月がぶら下がっている。深夜の孤立とスクリーンの光だけで組み立てられたイメージだ。

しかし影響はカラーグレーディングを超えている。*Serial Experiments Lain* は根本的に、物理世界とネットワークの境界の崩壊についての作品だった――自己とは思っていたほど確固たるものではないと少女が発見する物語。Rain98 はそれに近い何かを目指しているように見える。歴史とはたどっていく線ではなく、何度も入り直すループなのだ、という考えだ。

| 表層的な要素 | どこから来ているか | Rain98 がどう使っているか |
| --- | --- | --- |
| 青く染まった夜の街 | *Lain* の視覚言語 | 終わらない深夜のヘッドスペースを確立する |
| 疲れた、タバコを吸う主人公 | 1990年代アニメの図像 | セリフが届く前に燃え尽きを伝える |
| 繰り返し現れる月のイメージ | 平成のSFとアニメ | あらゆる時代に存在する冷たい目撃者 |
| 曖昧な技術 | サイバーパンクおよびその周辺のフィクション | タイムトラベルを魔法ではなくシステムのように感じさせる |

はっきり言っておく価値がある。*Lain* は明言された影響元であり、テンプレートではない。Rain98 の構造――二つの時代の二人が時間を超えて議論する――はそれ自体が独自のものだ。このゲームを *Lain* のクローンとして扱うと、それが実際にやっていることを見逃してしまう。

## デモが明かすもの、そして意図的に伏せるもの

デモは通しでおよそ3時間で、垂直スライスとしては異例なほど太っ腹だ。それでも、プレビュー記事は、1時間プレイしても中心的な問いはまだ答えられていないと指摘している。二人のキャラクターは、お互いが自分の状況を受け入れられないことにどう応じるのか？

それは欠陥ではない。ペーシングだ。Rain98 はデモの中で、前提を解決するのではなく、ムードと関係性を築くことに時間を使っている。ひねりのある展開を期待して臨むと、反発してしまうだろう。これまでのプレイヤー体験からすると、デモはトーンのサンプルとして扱うのが最良だ――この青く照らされたヘッドスペースに、フルレングスのゲームとして住みたいかどうかを決める機会として。

| 問い | デモ後の状況 |
| --- | --- |
| なぜ世界を終わらせねばならないのか説明しているか？ | いいえ――意図的に伏せられている |
| 二つの時代は直接交流するのか？ | はい、それが核となる設定 |
| 3時間のデモが物語のすべてか？ | いいえ、より大きなゲームの一部 |
| 分岐する選択肢は確認されているか？ | 入手可能な記事では確認されていない |
| 発売日は確定しているか？ | 参照した資料では確認されていない |

## 迷わず物語を追う方法

Rain98 は、繰り返しに注意を払うことに報いてくれるタイプのビジュアルノベルだ。イメージは戻ってくる。セリフは時代を超えて響き合う。プレイしながら Rain98 のストーリー解説を組み立てようとしているなら、以下の習慣が助けになる。

- **セリフだけでなく、繰り返し現れる物に注目する。** 月、タバコ、バルコニー、スクリーン――両方の時代に現れるものはすべて、テーマ的な役割を果たしている。
- **各シーンを誰が語っているかに注意する。** 二つの時代を扱う物語では、視点がしばしば仕掛けになる。
- **環境テキストを読む。** ビジュアルノベルは、セリフよりも背景の描写にキャラクター性を埋め込むことがはるかに多い。
- **早々にどちらかの側につく衝動を抑える。** このゲームの論旨全体は、両方の時代が妥協を強いられているというものだ。
- **短い年表をつける。** 相手の時代について各キャラクターが信じていることを、それが訂正される前に書き留めておく。

| 読解の習慣 | 何が得られるか |
| --- | --- |
| 繰り返されるイメージを注視する | 二つのタイムラインをテーマ的に結びつける |
| 誰が話し、誰が語るかを追う | 視点の転換を早くに明らかにする |
| 時代特有の語彙を記録する | 各キャラクターが相手をどう枠づけているかがわかる |
| 静止したシーンでゆっくりする | ペーシングが隠す伏線を捕まえられる |

Rain98 のストーリー解説を探している人にもう一つ言っておきたいのは、このゲームのタイトルと雨のイメージは偶然ではないということだ。平成の日本のメディアにおいて雨は、ほぼ常に「雰囲気を論拠にする」ための略記だ――晴れることを拒む天気、晴れない気分。雨が何かを意味すると期待しておこう。

## FAQ

**Rain98 はホラーゲームですか？**
ジャンプスケアの意味では違う。より心理的・雰囲気的な不安に近い――*Serial Experiments Lain* や *新世紀エヴァンゲリオン* と同じレジスターだ。Rain98 のストーリー解説を、わかりやすい怖がらせものとして探しているなら、それはこの作品ではない。

**完全版を理解するためにデモをプレイする必要はありますか？**
デモはプロローグの要約ではなく一部なので、必須ではないはずだ。とはいえ、3時間のデモは相当なトーンのサンプルであり、フルプレイに踏み切る前にペーシングが自分に合うかを決める最良の方法だ。

**Rain98 のデモを終えるのにどのくらいかかりますか？**
プレビュー記事によればおよそ3時間。約1時間プレイしたレビュアーがまだ導入段階にいると報告しているということは、このゲームが急いでいないことを物語っている。

**Rain98 は Serial Experiments Lain と関係がありますか？**
いいえ――*Lain* を影響元として挙げているオリジナル作品だ。共有されているDNAは美的でテーマ的だ。青い光、ネットワーク的な疎外感、そして1998年から眠っていないような見た目の主人公。

**完全版は「世界を終わらせる」問いに答えますか？**
それこそが物語が賭けているもの全てだ。デモは意図的に答えを伏せており、つまり報いは完全版で成立しなければならない――そしてそれがまさに、Rain98 のストーリー解説の議論が、答えが出た途端にはるかに大きくなる理由なのだ。
