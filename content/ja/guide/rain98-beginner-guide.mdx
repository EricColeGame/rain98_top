## 最初のセッションをきちんと準備する

多くの初心者が空気感重視のビジュアルノベルから離れてしまうのは、退屈な技術的理由からです。音響設定が違う、プレイ時間が違う、照明が違う。スタートを押す前にそれらを直せば、あとはゲームがやってくれます。

- **ヘッドホンを着用する。** 雨はもう一人の主役です。ノートPCのスピーカーは雨をホワイトノイズに潰し、部屋の質感を失わせます。
- **ボイスがあっても字幕をオンにする。** 玲奈の演技には、一度目では見落としやすいサブテキストが宿っています。
- **薄暗い部屋でプレイする。ただし真っ暗にはしない。** アパートの暖かいランプと冷たい窓のコントラストこそが、この作品の視覚的な主張そのものです。
- **既読スキップはオフのままにする。** 3時間のデモで未読行を誤って飛ばすのは、物語の糸を見失う最速の方法です。
- **テキスト速度は遅めから中程度に設定する。** 速いテキスト速度は流し読みを促しますが、このゲームは流し読みに罰を与えます。

| 設定 | 推奨 | 重要な理由 |
|---|---|---|
| 音声出力 | ヘッドホン | 雨の環境音と声のニュアンスが雰囲気を支える |
| テキスト速度 | 遅いまたは中程度 | 濃密な内心の独白の流し読みを防ぐ |
| 既読スキップ | オフ | 未読の物語の見どころを誤って失うのを防ぐ |
| 字幕 | オン | 声の演技がテキストボックス以上のサブテキストを加える |
| 部屋の照明 | 薄暗く、暗すぎない | アートが頼りにする暖冷のコントラストを保つ |
| セッションの長さ | 45〜60分 | 重いテーマは短いプレイ時間のほうが響く |
| セーブ習慣 | 各シーンの区切りで手動セーブ | 離席が必要になったときの安価な保険 |

内容についての簡単な注意：このゲームのマーケティング自体が、絶望と自己破壊をテーマとして打ち出しています。それは避ける理由にはなりませんが、3時間を一気に通すのではなく、休憩を計画する理由にはなります。

## 3時間のデモをどうペース配分するか

3時間は短く聞こえますが、暗い部屋で濃密な文章を読んでいるとそうでもありません。ここでは、デモの構成 — 物語の冒頭から第2章の前半まで — に沿ったおおよその計画を紹介します。すべてのプレイヤーが同じ速度で読むわけではないという前提は崩しません。

| おおよその時間帯 | やっていること | 初心者の目標 |
|---|---|---|
| 最初の15〜20分 | プロローグと導入 | スキップしたい衝動を抑え、部屋を吸収する |
| 20〜60分 | 第1章の序盤 | 玲奈の話し方と気分のパターンを学ぶ |
| 60〜120分 | 第1章の残り | 雰囲気が変わるとき雨がどう変化するか記録する |
| 120〜180分 | 第2章の前半 | ペースを落とす。ここがデモの終わり |

この区間のための実践的な習慣を2つ：

1. **会話の途中ではなく、シーンの切り替わりで止める。** 自然な区切りは、戻ってきたときに感情のビートを保ちます。
2. **短いメモファイルを用意する。** 1シーンにつき1行 — 何が変わったか、玲奈のどんな言葉が引っかかったか。30秒のコストで、デモのクリフハンガーがはるかに読みやすくなります。

初期のプレビュー記事に反映されているデモのプレイヤー体験によれば、大半の人が没入するか離れてしまうかの分かれ目は中間の1時間にあります。1時間のあたりで落ち着かないと感じるなら、それはたいていゲームが遅いのではなく、あなたが速く読みすぎているサインです。

## 雨粒のあいだを読む：注意を向けるべきこと

Rain98の雰囲気は飾りではありません — 物語を届けるシステムそのものです。環境音をBGMとして扱う初心者は、デモを終えて「何も起きなかった」と報告する傾向があります。それをテキストとして扱う初心者は、はるかに多くのものを持ち帰ります。

- **雨の変化に耳を傾ける。** 音量、リズム、そしてそもそも聞こえるかどうかは、このゲームで最も信頼できる感情の合図です。
- **光を観察する。** プレビュー記事は繰り返し、演出の核心にある矛盾を強調しています。外は冷たく終わらない土砂降り、内は暖かいランプに照らされた部屋。その緊張はテーマ的であり、偶発的ではありません。
- **玲奈が言わないことを追う。** 前提はすべての終わりを望むキャラクターを中心に据えているので、彼女の沈黙やはぐらかしは、発言以上に多くの情報を運びます。
- **時代に気づく。** 90年代後半の東京とは、特定の技術、特定の音楽、特定の孤独のあり方を意味します。細部は時代の質感であり、トリビアではありません。

| 気づくこと | たいてい何を意味するか |
|---|---|
| 雨が大きくなる | 緊張の高まり、またはシーンの転換が近い |
| 雨が静かになる | 親密な、または告白めいたビート |
| 室内の暖かい照明が強調される | 安らぎ、または偽りの安全の瞬間 |
| 玲奈が直接の問いをはぐらかす | 物語が意図的に隠している何か |
| 当時のテクノロジーが画面に入る | 接地。部屋の孤立感を思い出させる |
