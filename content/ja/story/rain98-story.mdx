Rain98は、シンプルで心に残る約束から始まります。東京、1998年、終わることのない雨、そしてすべてを終わらせたいと願う少女。無料体験版をプレイする前に**Rain98のストーリー**をすっきりと理解したいと考えているなら、このガイドでは前提、キャスト、舞台、そしてプレイヤーの選択が物語をどう形作るのかを扱います。**Rain98のストーリー**が重要なのは、それが本当は世界の終わりについての話ではないからです。それは、世界にもう一度朝が訪れる価値があるのかを、二人の孤独な十代の若者が決める物語なのです。

以下では、開発陣がこれまでに明かしたすべての内容、体験版が実際にどこまでを扱っているのか、そして物語の静かな瞬間をどう読み解くかを、整理して解説します。

## Rain98のストーリーは実際何についての話なのか？

本質的にRain98は、ビジュアルノベルの会話と探索、そして小規模なインタラクティブなシーケンスを組み合わせたナラティブアドベンチャーです。公式のSteamの説明は、一文でその雰囲気を伝えています。1998年の東京に降り続く終わらない豪雨、すべてを止めたいと願う少女、そしてその選択が世界を変える二人の孤立した若者。

この枠組みは、ジャンルについて多くを物語っています。これは派手な終末の物語ではありません。天候が感情であり、都市が登場人物であり、感情的緊張がまず個人的なもので、その後に世界的なものになる、ゆっくりとした雰囲気重視のキャラクター作品です。

| 項目 | 確認されている内容 |
|---|---|
| 舞台 | 東京、1998年 |
| 形式 | ビジュアルノベルのパートに加え、探索とミニゲーム |
| 開発元 | C#4R4CT3R |
| ディレクター | Shoon T |
| 主人公 | 雨原玲奈 |
| 玲奈の声 | 土屋理央 |
| 無料体験版のボリューム | 3時間以上 |
| 体験版の範囲 | 冒頭から第2章の前半まで |
| 製品版の状況 | 執筆時点では未発売 |

この物語は2025年4月に初めて発表され、それ以降複数のゲーミングイベントで披露されています。つまり、今日プレイヤーが試せるバージョンは、初期ビルドより大幅に洗練されているということです。

## 舞台設定：東京1998年と止まらない雨

1998年という年は偶然の選択ではありません。それはRain98のストーリーを、経済的不安、台頭するインターネット文化、そして特有の都市的憂鬱によって定義された十年の終盤に位置づけます。終わらない雨は、文字通りの障害であると同時に比喩としても機能します。人々を室内に閉じ込め、音を吸い込み、あらゆる会話が井戸の底で行われているように感じさせる何かです。

体験版に対するコミュニティの感想は、環境デザインを一貫して称賛しています。プレイヤー体験の報告では、ビジュアル、サウンドデザイン、キャラクターアート、環境アートが際立った要素として挙げられ、1998年という時代の表現が特に巧みに描かれていると指摘されています。こうした場所へのこだわりこそが、記憶に残るビジュアルノベルと忘れられるビジュアルノベルを分けるものです。

Rain98のストーリーの多くは静かな空間——部屋、通り、会話——で展開するため、感情的な重みの大部分は雰囲気が担っています。プレイする際は背景の細部に注目してください。それらはしばしば、台詞以上に多くの物語情報を運んでいます。

## 雨原玲奈とは誰か？

雨原玲奈はRain98のストーリーの感情的な中心です。彼女の声を務めるのは土屋理央で、彼女は本作のフィーチャーソングのボーカルバージョンも歌っています。これは開発陣が新しいトレーラーでSteamストアページを更新した際に強調した点です。同じ声が会話から音楽へと移行することで、キャラクターとテーマの間に強い連続性が生まれます。

主人公は、すべてを終わらせたいと願う人物として描かれています。これは物語の出発点としては重いものです。それを過激なポーズとして扱うのではなく、執筆陣はもう一人の主要人物が向き合わなければならない真摯な感情状態として扱っているようです。

| 物語の要素 | なぜ重要なのか |
|---|---|
| 玲奈の語る願い | 最初のシーンから中心的な対立を枠づける |
| 二人目の孤独な若者 | プレイヤーの視点であり、玲奈の対極となる存在 |
| 終わらない雨 | 内面の絶望を外在化し、登場人物たちを孤立させる |
| 1998年という年 | 90年代後半の都市日本という雰囲気に物語を固定する |
| 選択に駆動される構造 | 結末が最初から決まっているわけではないことを示唆する |

「二人の孤独な若者」という組み合わせは意図的なものです。Rain98のストーリーは二人芝居のダイナミクスの上に築かれており、そこでは親密さは共有された勝利ではなく、共有された孤立から育まれます。

## 無料体験版はRain98のストーリーにどう組み込まれているのか

体験版は、The MIX Fall Game Showcase 2026での新しいトレーラーの公開とともにSteamに登場しました。無料で、3時間以上プレイでき、物語の冒頭から第2章の前半までを扱います。今後の体験版アップデートで第2章の後半が追加される予定です。

Rain98のストーリーが自分の時間に値するかどうかを見極めたい人にとって、3時間は十分すぎるほどです。雰囲気を確立し、中心となる関係を紹介し、製品版に踏み切る前にインタラクティブなシステムを試すのに十分な長さです。

| 物語のセグメント | 体験版で遊べるか？ |
|---|---|
| 冒頭とプロローグ | はい |
| 第1章 | はい |
| 第2章 前半 | はい |
| 第2章 後半 | 今後の体験版アップデートで予定 |
| 第3章以降 | 製品版のみ |

体験版は完全にローカライズされていることも重要で、これは雰囲気に大きく依存する物語にとって意味があります。対応言語は以下の通りです。

- 英語

- 繁体字中国語
- 韓国語
- ブラジルポルトガル語
- ラテンアメリカスペイン語
- フランス語

配信や動画制作は、収益化の有無にかかわらず明示的に許可されています。ただし、クリエイターはSteamストアページへのリンクを貼り、#Rain98 ハッシュタグを使用する必要があります。

## 選択肢、ミニゲーム、そしてRain98のストーリーがどう分岐するか

体験版はビジュアルノベルのパートを拡張し、新しいインタラクションやミニゲームを追加し、探索できる街の範囲を広げました。これらは単なるテンポの休憩ではありません。Rain98のストーリーが登場人物間の親密さを築く方法そのものです。玲奈とのカードゲームに勝つことで、会話ツリーでは伝えられない彼女の一面を学べます。

| 要素 | 物語における役割 |
|---|---|
| ビジュアルノベルのパート | メインプロットと会話の選択肢を届ける |
| ミニゲーム | 絆を深める瞬間と軽い緊張の緩和を生み出す |
| 街の探索 | 1998年の東京を舞台にした環境ストーリーテリング |
| ステッカーと目標 | 積極的な関与に報いる任意のゴール |

コミュニティの報告によると、少なくとも一つのミニゲーム——大富豪のカードゲーム——が混乱を引き起こしており、あるプレイヤーは関連する目標が完了しないまま10ラウンド以上勝ったとされています。これは確定した設計上の欠陥ではなく、プレイヤー体験の報告として受け止め、目標が進まないように思える場合はSteamコミュニティのディスカッションを確認してください。

より大きな要点は構造的なものです。開発陣は二人の孤独な若者の選択が世界を変えると述べており、初期のプレイヤーフィードバックは執筆陣が生み出せる緊張感を称賛しています。一部のコミュニティメンバーは、製品版でより分岐の多い「道を外れる」タイプのルートを求めており、これはRain98のストーリーの分岐の可能性が最も期待されている特徴の一つであることを示唆しています。

## テーマと雰囲気：この物語が心に残る理由

雨、終わり、孤立、そしてつながりの可能性——これらがRain98のストーリーを支える四本の柱です。雨は絶え間なく降り続くため、物語はスペクタクルに頼ることができません。キャラクターに頼るしかないのです。

ディレクターのShoon Tは、プロジェクトをプロットのひねりではなく、その感情的な核を中心に据えてきました。体験版の感想によれば、その結果は美しさと憂鬱さを等しく感じさせるゲームであり、サウンドトラックはフィーチャーソングで初めてボーカルを携えています。

不快な感情と共に座っていることを信頼してくれるナラティブゲームを楽しむなら、これはきっと響くでしょう。絶え間ない前進を必要とするなら、意図的なテンポはあなたの忍耐を試すかもしれません——そしてそれは、これほど自らの雰囲気に忠実な物語にとっては妥当なトレードオフです。

## 物語を最大限に楽しむためのヒント

- **ヘッドホンでプレイする。** サウンドデザインは繰り返し長所として挙げられており、雨の多いシーンは注意深い傾聴に報います。
- **環境を読む。** 探索パートには理由があります。背景の細部はしばしばキャラクターの状態を補強します。
- **ミニゲームをきちんと試す。** 短いですが、キャラクターの読み方に彩りを加えます。
- **選択の前にセーブする。** 物語は結果を示唆しているので、結末を比較したいならバックアップルートを残しておきましょう。
- **フィードバックを共有する。** 開発陣はSteamコミュニティと公式Discordを通じて体験版のフィードバックを積極的に集めています。
- **後でもう一度体験版をチェックする。** 第2章の後半が予定されているため、体験版の物語範囲は広がります。

## よくある質問

**Rain98のストーリーはもう完成していますか？**
いいえ。製品版はまだ発売されていません。現在利用できるのは、冒頭から第2章の前半までを扱う無料体験版で、今後のアップデートで第2章の残りが追加される予定です。

**体験版をクリアするのにどのくらいかかりますか？**
開発陣によると3時間以上で、ビジュアルノベルの分野でもかなり充実した無料体験版の一つです。

**Rain98のストーリーの主人公は誰ですか？**
雨原玲奈で、声は土屋理央が担当しています。彼女は東京1998年における二人の孤独な若者の一人であり、すべてを終わらせたいという願いが中心的な対立を駆動します。

**Rain98のストーリーについて配信や動画制作はできますか？**
はい。開発陣はライブ配信やゲームプレイ動画を、収益化の有無にかかわらず許可しています。ただし、Steamストアページへのリンクを貼り、投稿時に #Rain98 ハッシュタグを使用する必要があります。

**選択によって物語は変わりますか？**
前提では、二人の主人公の選択が世界を変えると明言されています。コミュニティの議論では、プレイヤーが製品版でより分岐の多いルートを期待していることがうかがえるため、序盤の選択は飾りではなく意味のある布石として捉えておきましょう。
