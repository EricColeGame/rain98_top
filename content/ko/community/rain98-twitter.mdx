| 경품 이벤트 | 상품, 참여 단계, 자격 안내 | 사인 굿즈와 프로모션 아이템을 받을 기회 |

| 수익화 | 수익화 여부와 관계없이 허용 — 별도 허가 요청 불필요 |
| 콘텐츠 유형 | 실시간 스트리밍과 업로드 영상 모두 해당 |
| 필수 링크 | 영상 설명에 Steam 스토어 페이지 URL 포함 |
| 권장 태그 | 스트림이나 영상을 게시할 때 `#Rain98` 사용 |
| 적용 범위 | 데모 빌드에 적용 |

이는 많은 소규모 출시작이 제공하는 것보다 친화적인 정책이며, 가장 흔한 걸림돌을 제거합니다. 크리에이터가 먼저 누군가에게 이메일을 보내야 하는지 궁금해하는 부분인데, 그럴 필요가 없습니다.
